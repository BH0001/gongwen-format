# 格式基线与实现边界

核实时间：2026-10-08。GB/T 9704—2012 为现行推荐性国家标准，最近一次复审为2025-05-30，结论继续有效。

- [国家标准平台](https://std.samr.gov.cn/gb/search/gbDetailed?id=lOIe27f77QU%3D&mode=p)
- [政府机构公布的标准全文](https://jcy.xjbt.gov.cn/c/2019-01-31/7176573.shtml)

本技能实现正文公文排版，不生成版头、版记、红头、印章，不检验纸张白度、印刷、装订等物理要求，不能把输出称为通过全部国标认证。

| 要素 | 国标依据 | 软件实现 |
|---|---|---|
| 页面 | A4；上37±1mm、左28±1mm；版心156×225mm，5.1—5.2.1 | 上37、下35、左28、右26mm；已有横向节保留并报告例外 |
| 正文 | 一般三号仿宋、黑色；首行空二字，5.2.2、5.2.4、7.3.3 | 16pt，仿宋_GB2312/仿宋，首行二字，段前段后零 |
| 行字数 | 一般22行×28字，特殊情况可调整，5.2.3 | 默认固定值28.9pt行距、勾选对齐到网格；实际行字数需渲染验证 |
| 标题 | 一般二号小标宋，居中，保持词意，7.3.1 | 22pt；字体优先方正小标宋简体，避免标题孤行；长标题检查换行语义 |
| 一级至四级 | 一、黑体；（一）楷体；1.、（1）仿宋，7.3.3 | 三号，不额外加粗；默认不改写序号 |
| 主送机关 | 标题下空一行、左顶格，7.3.2 | 三号仿宋；原文缺少冒号只提示，不擅自补字 |
| 无印章署名日期 | 署名右空二字；日期按署名及长度定位，7.3.5.3 | 根据中西文宽度估算左缩进，署名与日期保持同页；须渲染检查 |
| 附件说明 | 正文下空一行、左空二字，续行对齐名称，7.3.4 | 使用悬挂缩进；不自动创造附件名称或序号 |
| 附件正文 | 另面；附件标识左顶格三号黑体、第三行居中标题，7.3.7 | 显式映射 attachment-label 与 attachment-title；另面且留一行 |
| 页码 | 四号半角宋体、两侧一字线；奇右偶左各空一字，7.5 | PAGE 域、14pt宋体、奇偶页外侧；页脚距页面下缘26mm为实现初值，必须检查一字线与版心下缘距离 |

固定28.9pt是本技能的默认软件参数，不是标准明文规定的唯一行距；字体品牌、GB2312/GBK等字库名称也不是统一强制要求。默认正文及各级标题显式设置固定值28.9pt，普通正文勾选对齐到网格，使段落窗口直接显示固定行距类型与数值。严格保留的特殊段落仍以输入原稿的设置为准。用户明确要求网格模式时，正文按版心推导约29pt行网格，段落窗口可能显示单倍行距；此模式须在交付时说明。标题不参与普通正文字符网格，以保证22pt字体不受正文格宽挤压。

在156mm宽版心中，28个16pt全角字略宽于可用空间。国标配置采用约-0.25pt的字符间距微调，保留三号字大小，并显式关闭Word自动按网格调整右缩进；后者可能使日期意外换行。这些是经过本机Word渲染校准的软件参数，不是国标逐字规定。署名与紧接其前的正文或附件说明保持相邻，避免自然分页单独留下签署页；原文已有的手动分页与空段保留。

## 示例通知配置

`sample-notice` 提供以下示例参数：A4、37/35/28/26mm页边距；标题方正小标宋简体22pt，正文仿宋_GB2312 16pt；一级黑体、二级段内题头楷体_GB2312；主送机关同为楷体；固定28.9pt行距；署名日期居中加八字首行缩进；奇偶外侧14pt宋体页码。

示例通知配置仅提供版式参数，不包含业务正文。`examples/notice.md` 为虚构的演示材料；图片、表格、公式、批注和修订等复杂内容由回归脚本生成并验证。输入文档已有的手动分页、空段、“（此页无正文）”和未填完整的日期均予保留；新文档使用自然分页，不主动加入这些内容。

## 自定义配置

复制两套JSON配置之一，用 `--profile /absolute/path/custom.json` 指定；尺寸为毫米，字号为磅。`lineMode` 为 `grid` 或 `fixed`，默认与示例通知均为 `fixed`、`fixedLinePt: 28.9`；`alignToGrid` 默认为 `true`，普通正文勾选对齐到网格，可在自定义配置设为 `false`。`grid` 仅用于明确要求网格排版的任务。`signatureMode` 为 `unsealed` 或 `sample`。字体按候选列表顺序选择已安装项，显式 `--font role=字体` 覆盖该角色，缺字库不会静默替换。用户改动的参数应在回复中说明，不再笼统称为默认国标配置。
